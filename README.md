# Hanamaru Solutions Website

Simple corporate website for Hanamaru Solutions, built with Vue 3 and Vite.

See [docs/spec.md](docs/spec.md) for the specification.

## Run locally

```bash
npm install
npm run dev
```

The dev server runs at http://localhost:5173.

## Build

```bash
npm run build
```

Output goes to `dist/`.

## Tests

```bash
npm run test:run
```
